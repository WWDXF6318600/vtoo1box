视频链接 / 直链
这一项有硬限制，说明白：
抖音/快手/视频号的链接解析必须有一个服务端去请求平台接口，而浏览器里做的网页被跨域策略挡住，纯离线文件做不到。
另外平台大多要求链接来自已备案域名。所以这一页只对「能直接访问的 mp4 直链」和「你自己填的解析接口（且该接口允许跨域）」有效。

怎么用

保存到手机在浏览器菜单里选「添加到主屏幕」，之后点桌面图标就能离线打开，跟 App 一样。
需要联网吗不需要。图片去水印、去字幕、去重全部在你手机本地算。只有「文案提取」需要你自己的接口。
文件会上传吗不会。这个页面没有任何服务器，你选的文件只在浏览器内存里。
支持多大视频建议 3 分钟以内、1080p 及以下。太长的会占满手机内存被浏览器杀掉。

常见问题

提示找不到编码器需要用 Chrome / Edge 94 以上版本。手机自带浏览器、微信内置浏览器基本都不行。
视频读不出来只支持 MP4 / MOV。MKV、AVI、FLV 请先用其它工具转成 MP4。
画面躺倒了在「处理方式」里把旋转改成 90° 或 270° 再试。
自动找的框不准自动识别只是提示，做不到百分百准。点框可取消选中；找漏了就切到「框选」自己拖一个框，或直接用手指涂抹。修复时只会动水印笔画，不会整块糊掉。
智能修复很慢它是逐帧把字幕擦掉再补背景，一分钟视频大概要几分钟。赶时间就选「模糊盖住」。
处理后还是被判重复把强度调到重度，再打开抽帧。平台比对的是画面指纹，改动要足够大才行。

和之前那个版本的区别

之前给的是电脑上跑的服务版，需要装环境、开服务、手机连同一个 WiFi。这个版本是单个 HTML 文件，下载到手机、用浏览器打开就能用，不用装东西也不用开电脑。

代价是：视频解析下载（抖音/快手无水印）这种必须走服务端的功能，离线版做不了。
